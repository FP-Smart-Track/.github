# FP Smart Track – Organization Configuration

Este repositorio no contiene código del proyecto.

Su finalidad es centralizar la configuración común de la organización FP Smart Track.

## ¿Qué contiene?

- Plantillas oficiales de Issues
- Plantilla oficial de Pull Request
- Protocolo de contribución
- Normas de comunicación técnica

## ¿Por qué existe?

Permite que todos los repositorios de la organización:

- Utilicen el mismo modelo de ticketing
- Apliquen las mismas plantillas de Issues
- Sigan el mismo flujo de trabajo
- Mantengan coherencia entre equipos Web y App

## ¿Afecta al código?

No.  
Este repositorio únicamente define configuraciones compartidas a nivel organizativo.

## Uso previsto

Las plantillas aquí definidas se aplican automáticamente a los repositorios que no tengan sus propias plantillas locales.

Cualquier modificación en este repositorio impactará en el modelo de trabajo común del proyecto.
